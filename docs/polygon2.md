# 2D polygon triangulation and convex decomposition

`geometry_kernels::polygon2` preprocesses one closed f64 boundary (`[f64; 2]` vertices, implicit closing edge, no holes) for collision and geometry consumers. `triangulate_polygon2` is ear clipping; `convex_decompose_polygon2` applies Hertel–Mehlhorn to that triangulation; `validate_simple_polygon2` runs the normalization and simplicity checks alone. The algorithms follow the scope of `pmndrs/math` `polygon2-triangulate` / `polygon2-decompose`; no source is copied and no circumcircle helper is added because both algorithms need only orientation predicates.

Input contract, applied in order: non-finite coordinates are `NonFiniteVertex`, a bounding-box span whose square overflows is `UnrepresentableExtent`, and more than `u32` vertices is `TooManyVertices`. Consecutive vertices within the scale tolerance `4ε(max|x| + max|y|)` per axis, including a closing repeat of the first vertex, collapse to the first of the run. A vertex within tolerance of the line through its neighbours that continues forward is straight and leaves the working boundary; one that turns back (a zero-width spike) is `SelfIntersection`. Fewer than three remaining vertices is `TooFewVertices`; zero area within tolerance (collinear or cancelling input) is `ZeroArea`. Both windings are accepted; the summary reports the input winding and every output is counter-clockwise. With `SimplicityCheck::Validate` every non-adjacent edge pair is tested with closed-segment predicates, so crossings, touching vertices and non-consecutive repeated points are `SelfIntersection` naming the first pair in boundary order. `SimplicityCheck::AssumeSimple` skips that O(n²) test as a caller precondition; violated input never panics or loops and yields an error (`NoEar`) or an unspecified tiling. No API panics on bad input.

Output contract: indices refer to the input slice. The working boundary starts at its lexicographically smallest vertex and runs counter-clockwise, so equal inputs give bit-identical output, and inputs without near-duplicates give identical output coordinates under cyclic rotation and reversal. Triangulation emits exactly `boundary_vertices − 2` positive-area triangles `[previous, tip, next]` in clipping order. Decomposition removes each diagonal, in triangle order, whose removal leaves both endpoints non-reflex; pieces are compressed rows (`indices`, `offsets`), ordered by their first triangle and starting at that triangle's first vertex. Pieces are convex but may keep a straight vertex where a removed diagonal ended. Hertel–Mehlhorn keeps only essential diagonals, so it returns at most `2r + 1` pieces for `r` reflex vertices and at most four times the optimum; it is not a minimum decomposition. Straight and repeated input vertices are never referenced.

Complexity and allocation: normalization O(n), validation O(n²), ear clipping O(n·r) with incremental ear flags and a non-convex candidate list (O(n) for convex input, O(n²) worst case), Hertel–Mehlhorn O(n) over half-edges. A lap without an ear (counted by `Polygon2Work::stalls`, zero across the test suite) refreshes all flags, then retries with exact predicates before returning `NoEar`. All buffers live in a caller-owned `Polygon2Work` and the output `Vec`/`ConvexDecomposition2`; warmed reuse allocates nothing (`tests/allocation_regressions.rs`).

Evidence (`tests/polygon2.rs`): 300 seeded star-shaped and 2-opt random polygons (both windings) check triangle count, positive orientation, area preservation, index validity, winding, piece convexity, the `2r + 1` bound, maximality (every kept diagonal is essential) and 400-point sampled coverage against an independent crossing-number point-in-polygon oracle for triangles and pieces. 1500 small (3–10 vertex) polygons check every interior triangle edge against a brute-force diagonal oracle, require exactly `n − 3` distinct diagonals, and match a naive exact O(n³) ear clipper triangle-for-triangle. Further tests cover rotation/reversal invariance, reused work versus fresh runs and `AssumeSimple` versus `Validate`, fixtures for concave (L, U, arrow, combs), collinear (midpoints across the wrap-around, edge fans), repeated and near-repeated, nearly-degenerate (needle, 1e-13 near-straight vertices, thin notch, 1e6 offsets, 1e-9 scale) and convex (one piece) polygons, every typed error, 500 random crossing inputs under `AssumeSimple` without panics, and a linear ear-test work bound on star polygons.

Developer-facing Divan workloads (`cargo bench -p geometry-kernels --bench polygon2 -- --sample-count 30 --threads 1 --color never`) cover convex regular, seeded random-star and comb shapes at 16, 256 and 2048 vertices.
